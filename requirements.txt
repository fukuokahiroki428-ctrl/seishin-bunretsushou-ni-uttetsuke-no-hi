# Predormition 번들 Python 의존성 — 버전 고정(pin)
#
# 왜 고정하나
#   예전엔 bundle_python.sh / bundle_python_win.bat 이 `pip install twikit httpx ...` 처럼
#   버전 없이 설치해서, 같은 커밋을 1년 뒤에 빌드하면 전혀 다른 버전이 들어왔다.
#   twikit 이 X API 파싱을 바꾸거나 pydantic 이 major 를 올리면 빌드는 성공하는데
#   수집만 조용히 깨진다 — 원인을 찾기 가장 어려운 형태의 고장이다.
#
# 여기 적힌 버전은 실제로 동작을 확인한 조합이다(2026-08 기준, Python 3.14).
#
# 업데이트 방법
#   1) 앱의 설정 → "모듈 업데이트" 로 최신을 받아 실사용으로 검증한 뒤
#   2) 아래 명령으로 이 파일을 갱신하고 커밋한다:
#        <python> -m pip list --format=freeze | grep -iE '^(twikit|httpx|atproto|openpyxl|pillow|piexif|browser.cookie3|yt-dlp|beautifulsoup4|websockets|lxml|m3u8|cryptography)='
#   ※ 런타임 업데이트(앱 안에서 최신 받기)는 이 파일과 무관하게 계속 동작한다.
#      이 파일은 '빌드 시점에 무엇을 넣을지'만 정한다.
#
# 전이 의존성(pydantic, certifi 등)은 일부러 고정하지 않는다 —
#   해시까지 고정하려면 플랫폼별 wheel 을 전부 나열해야 해서 관리비용이 급증한다.
#   직접 의존성만 고정해도 '조용한 동작 변화'의 대부분은 막힌다.
