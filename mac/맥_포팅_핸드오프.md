# 맥 버전 포팅 핸드오프 — Windows(v3.0)에서 가져올 변경

Windows 포트(`windows/`, v3.0)에서 적용한 변경 중 **맥(`mac/chernobyl`, `mac/pen`)에 아직 없는 것**을 정리한다.
핵심 로직(미러/엔진/YouTube 댓글)은 **Qt6 C++/JS 라 플랫폼 무관 → 대부분 그대로 복사**하면 되고,
프로세스/콘솔/프로세스-정리만 맥 방식(Terminal.app, pkill/pgrep)으로 바꾸면 된다.

> 맥은 Chernobyl(`mac/chernobyl`)과 PEN(`mac/pen`)이 **별도 앱**이다. Windows에선 한 앱(カメラ)으로 통합했지만,
> 맥은 그대로 둘로 두고 **각 기능을 해당 앱에 포팅**한다 (미러/엔진 → pen, YouTube → chernobyl).

---

## 0. 맥에 이미 있어 포팅 불필요
- ✅ **YouTube 설명 임베드** (`--embed-metadata`) — `mac/chernobyl/.../MiyoBackend.cpp` 에 이미 있음.
- ✅ **YouTube @handle/UC URL 리졸버(404 수정)** — 맥에 이미 있음. (Windows는 맥에서 가져온 것)
- ✅ **캡쳐 Chrome 전용 프로필** (`chrome_capture_profile`) — 맥 `RealChromeCrawler` 에 이미 있음.

## 1. ★ GNUBoard 등 엔진 분석 미러 — `mac/pen/src/core/PenBackend.cpp`
가장 큰 작업. 참조 구현: **`windows/src/core/PenBackend.cpp` → `crawlSiteMirror()`** (전부 플랫폼 무관 — 거의 그대로 복사).
맥 `crawlSiteMirror` 는 **구버전**이라 아래가 전부 빠져 있다:

| 가져올 것 | 핵심 | 비고 |
|---|---|---|
| **쿼리스트링 파일명 분리** ★최우선 | `urlToLocalPath` 가 `qu.query()` 를 파일명에 포함 (`board.php?bo_table=X&wr_id=N` → `board.php__bo_table-X__wr_id-N.html`). 길면 MD5 축약, 충돌 시 `-2`. | **이게 없으면 게시판 글이 전부 `board.php` 한 파일로 충돌해 미러가 빈다.** 맥도 동일 버그. |
| **엔진 자동 감지** | 첫 페이지에서 JS 프로브 — `var g5_url`/`g5_bbs_url`/`wrest.js`(GNUBoard), `/wp-content/`(WP), `?mid=`(XE/Rhymix) 등. `m_detectedEngine` 저장 + UI `onEngineDetected`. | generator 메타 의존 금지(GNUBoard는 안 씀). 시그니처 근거: `github.com/gnuboard/gnuboard5`. |
| **`&amp;` 링크 재작성** | 재작성 루프에서 `srcUrl` 와 `&`→`&amp;` 치환형 **양쪽** 모두 치환. | DOM `a.href`는 `&`, 저장 HTML 속성은 `&amp;` → 안 하면 게시판 링크가 로컬 연결 안 됨. |
| **액션 URL 스킵 필터** | `shouldSkip` — `/login.php`,`/register`,`/write`,`/delete`,`/good.php`,`/scrap`,`/memo`,`/ajax.` … + 검색/정렬 파라미터 `sfl=`,`stx=`,`sst=`,`sod=`,`sop=`,`spt=`,`sca=`. `/스크립트.php` 정확 매칭(게시판 이름 오탐 방지). | GNUBoard5 `bbs/` 전수 기준. 크롤 폭주 방지도 겸함. |
| **페이지 제목 수집 + 그룹/검색 인덱스** | `m_mirrorTitles[url]` 수집 → `mirror/index.html` 을 엔진 배지 + `bo_table` 별 그룹 + 실시간 검색 필터(JS)로 생성. | `index.html` 생성부 전체 교체. |
| **파일명 충돌 방지** | `QSet usedLocalPaths` 로 서로 다른 URL이 같은 파일명이면 `-2`,`-3` 분리. | |

추가: Windows에선 미러 **방식을 단일화**(딥/트위터/자동/인터랙티브/사이트 5모드 → 통합 미러 하나)했다.
맥 PEN UI에도 동일 적용 권장 — `onCrawlStarted` 분기 제거, `crawlSiteMirror(downloadMedia=true)` 하나만 호출.
(맥은 `crawlDeepMirror`/`crawlTwitterMirror`/`crawlAuto` 가 8곳 남아있음 → 통합 미러로 흡수.)

헤더에 멤버 추가: `QMap<QString,QString> m_mirrorTitles;`, `QString m_detectedEngine;` (`PenBackend.h`).
include: `<QUrlQuery>`, `<QCryptographicHash>`, `<QJsonObject>`.

## 2. 캡쳐 Chrome 분리(겹침/꺼짐 수정) — `mac/pen/src/platforms/RealChromeCrawler.cpp`
**증상:** 같은 캡쳐 프로필을 쓰는 잔존 Chrome이 살아있으면, 새 Chrome이 그 인스턴스로 핸드오프되며 즉시 종료.
**Windows 수정:** Chrome 기동 직전, 포트 리스닝 여부와 무관하게 **같은 프로필을 쓰는 chrome 프로세스 전부 정리**.

맥 적용 (맥은 이미 `pgrep`/`pkill`/`lsof` 인프라 있음 — 포트 기준만 하던 걸 **프로필 기준**으로 확장):
```bash
# 포트뿐 아니라 캡쳐 프로필을 쓰는 잔존 Chrome 도 정리 (개인 Chrome 은 프로필 경로가 달라 안 건드림)
pkill -f "chrome_capture_profile"      # 또는: pgrep -f → kill
```
→ `start()` 의 좀비 정리 블록(`#ifndef Q_OS_WIN` 쪽 lsof 부분)에 프로필-매칭 pkill 추가.

## 3. YouTube 댓글 수집 — `mac/chernobyl/src/core/MiyoBackend.cpp`
맥엔 **댓글 수집/후처리가 없다**(설명 임베드·핸들 리졸버는 이미 있음). 참조: **`windows/.../MiyoBackend.cpp` `runYoutubeDownload()`**.

1) 플래그(설정 토글 `config["comments"]` 로 게이트):
```cpp
if (config["comments"].toBool()) {
    baseArgs << "--write-comments";
    baseArgs << "--extractor-args" << "youtube:comment_sort=top;max_comments=300";
}
```
2) 후처리 — `info.json` 의 `comments[]`(필드: `author`,`author_url`,`author_thumbnail`,`text`,`like_count`,`author_is_uploader`)
   → 읽기 좋은 `<base>.comments.txt` 로 변환(작성자명 + [작성자] + 프로필 + 텍스트 + 👍좋아요).
   다운로드 후처리 블록(mediaPath 확정 직후)에 추가.

> 실검증(Windows v3.0): "Me at the zoo" 로 댓글 50개 + 설명 임베드(exiftool 확인) + `@YouTube`/`@google` 핸들 해석 정상.
> 같은 yt-dlp 호출이라 맥에서도 동일하게 동작한다 (yt-dlp/ffmpeg/exiftool 번들만 맥용으로).

## 4. 보조 프로세스/콘솔 — 맥은 선택(플랫폼 차이)
Windows 변경은 **작업관리자에 따로 뜨던 콘솔창 제거 + 앱 하위 중첩**이었다. 맥 대응물은 **Terminal.app 로그 창**
(`launchChildConsole` 대신 맥은 `osascript`/Terminal.app 로 띄움 — `mac/chernobyl/.../MiyoBackend.cpp` 에 13곳).
같은 UX(팝업 없는 백그라운드)를 원하면 맥도 Terminal.app 로그 창을 띄우지 말고 **인앱 로그로만** 처리.
(단, 이번 사용자 요청은 Windows 작업관리자 맥락이었으므로 맥은 **선택**.)

> 맥 전용/무관: Win11 DWM 둥근 모서리, `taskkill`/`netstat`/PowerShell CIM, `.rc` VERSIONINFO, `/utf-8`,
> SingleFile lib 경로(`tools/...`) 등은 Windows 전용 — 맥은 해당 없음.
