# 공작함 아카시 (工作艦 明石) — 한이시키 정비 공구함

한이시키를 고치고, 고친 것을 확인하고, 내보내는 공구들이다. 약속은 셋이다.

- **설치할 것이 없다.** 파이썬 표준 라이브러리만 쓴다. 맥 기본 `/usr/bin/python3`(3.9)로 돈다.
- **사용자의 앱과 자료를 건드리지 않는다.** 화면 점검은 격리 사본(홈 · 임시 폴더 · 앱 번들까지 따로)에서 한다.
- **비밀을 찍지 않는다.** 쿠키 · 토큰 · 비밀번호는 이름과 길이만. 공개 저장소에 올라가는 공구라 사람 이름도 박지 않는다.

## 바로 쓰기

```bash
cd mac/chernobyl
python3 akashi/inspect_all.py --doctor --hotfix   # 정기 점검 — 새 빌드마다, 설치·판 내기 전에
python3 akashi/tests/run_all.py                   # 기능 시험 — 크롤 · 캡처 · 이어받기를 실제로(약 15분)
python3 akashi/iso.py start                       # 격리 사본 하나 띄우기 (끄기: iso.py stop)
```

## 공구를 더할 때

- 표준 라이브러리만. `lib/` 을 쓴다 — `lib.cdp.Page`(화면) · `lib.paths`(앱·자료 찾기) · `lib.proc`(PID 로만 다루기).
- 머리에 한국어 설명: 쓰는 법, 그리고 **"★ 왜"** — 겉보기와 다른 결정의 까닭.
- 바꾼 것은 되돌린다(탭 · 창 크기 · localStorage · 가로챈 함수). 사본 밖은 건드리지 않는다.
- 비밀은 이름과 길이만. 경로는 `paths.short()` 로. 사람 이름을 박지 않는다.
- 바깥으로 나가는 일은 묻고, `--dry-run` 을 둔다.
- 올리기 전에 `privacy_scan.py`.

## 윈도우에서

화면 점검(`check_*` · `shots` · `hotfix_lab` 의 판정)은 CDP 로 화면에 붙으므로, 앱을 `QTWEBENGINE_REMOTE_DEBUGGING=127.0.0.1:<포트>` 로
띄우기만 하면 윈도우에서도 같은 코드가 돈다. 다만 `iso.py` 는 맥의 `HOME · CFFIXED_USER_HOME · TMPDIR` 와 APFS 복제를 쓴다.
윈도우라면 `APPDATA · LOCALAPPDATA · USERPROFILE · TEMP` 를 따로 주고, 번들 대신 설치 폴더를 복사해 띄워야 한다(아직 해 보지 않음).
`lib/proc.py` 의 실행 파일 경로 묻기도 맥의 libproc 이라 윈도우 판이 필요하다.
