# 수리법 — 증상에서 고치기까지

각 항목은 **증상 → 확인 → 고치기 → 다시 확인** 순서다. 명령은 `mac/chernobyl` 에서 친다.

## 수집이 「0개」 로 끝났다 (오류도 없이)

- 확인: 앱 로그의 `[모양바뀜]` · 「HTTP 200 인데 0개」 줄. 수리 도우미에 "○○ 안 돼" 라고 물으면 "서비스가 응답 형식을 바꿈" 으로 짚는다.
- 고치기: 옛·새 응답을 저장해 `python3 akashi/shape_dump.py old.json --compare new.json`. 새 이름을 `hotfix/shape_aliases.json` 에 넣고
  고침 꾸러미로 낸다(`docs/응답모양.md`). 구조가 통째로 바뀌었으면 코드를 고친다.
- 다시 확인: 같은 대상으로 수집 → 개수가 나오는지.

## 인스타그램이 401 · 429 를 섞어 준다 (로그인 문제처럼 보인다)

- 확인: 죽은 끝점을 부르고 있지 않은지. 지금 살아 있는 길은 `POST /graphql/query`(doc_id + lsd/fb_dtsg).
  자세한 실측은 `mac/chernobyl/docs_instagram_2026-09.md`.
- 고치기: doc_id 가 낡았으면 앱이 스스로 되살린다(토큰 새로받기 → `resources/tools/ig_docids.py` 로 번호 떠 오기).
  계속 막히면 떠 온 번호를 고침 꾸러미 `api_overrides.json` 의 `instagram.*DocId` 로 낸다.
- 함정: 실패를 상태 코드로 가르지 않는다 — 낡은 doc_id 는 HTTP 400 + 108바이트, 낡은 provider 깃발은 HTTP 200 + 194바이트.

## 트위터 GraphQL 번호가 바뀌었다

- 확인: 로그에 404 · "query not found". 웹에서 새 경로 `/i/api/graphql/<해시>/<이름>` 을 얻는다.
- 고치기: 고침 꾸러미 `api_overrides.json` 에 `twitter.<이름>` 으로. 앱은 그 모양의 경로만 받는다.

## 앱이 튕겼다

- 확인: `python3 akashi/crash_report.py` → `--latest`. ★ 줄이 우리 코드다.
- 뜻: SIGSEGV/SIGBUS + ★ 줄 → 우리 버그(널 · 해제된 메모리 · 서로 다른 임시 객체의 begin/end — 2026-09 팬박스 충돌이 그랬다).
  SIGBUS + KERN_MEMORY_ERROR → 켜 둔 채 설치했거나 번들이 다시 서명됐다(코드 버그 아님 — `install.py` 로 설치).
- 다시 확인: 같은 동작을 격리 사본에서(`iso.py start` → 재현).

## 화면이 깨졌다 · 단추가 안 보인다

- 확인: `python3 akashi/check_layout.py --seed-targets 17` (5폭 × 15화면) · `python3 akashi/check_console.py`(JS 오류 — 한 줄이 틀려도 탭이 통째로 죽는다).
  눈으로: `python3 akashi/shots.py --tabs <탭> --widths 1180,800,420 --themes light,dark`.
- 고치기: `resources/html/index.html` 의 `#fx-layout` · `#settings-board-layout` · `fxAdapt()` (`docs/화면배치.md`).
  빌드 없이 볼 때는 격리 사본의 번들 복제본에 html 을 넣고 새로 고친다.
- 다시 확인: 같은 점검 + `check_adapt.py`.

## 창 끌기가 굼뜨다

- 확인: `python3 akashi/drag_watch.py` 를 켜고 끌어 본다. 「창 서버에 맡김」 이 없으면 예비 타이머 길. `--anywhere` 로 판단 쪽과 네이티브 쪽을 가른다.
- 고치기: `docs/창끌기.md`.

## 설정 · 계정이 사라진다

- 확인: `python3 akashi/check_forms.py`. 기능 창을 하나 열어 두면 9번(진짜 두 창)까지 본다.
- 고치기: `docs/폼저장.md` 의 불변식 — 바뀐 칸만 보내기 · 합치기 · 알리기.

## 도구(ffmpeg · yt-dlp · 파이썬)가 안 돈다

- 확인: `python3 akashi/doctor.py` — 번들 도구 실행 · 모듈 import · 아키텍처(로제타 의존) · 서명.
- 고치기: 앱의 설정 → 유지보수(모듈 업데이트 · 파이썬 복구) 또는 수리 도우미에 "고쳐". 번들에서 빠진 것이면 다시 빌드.

## 판을 내야 한다

1. `./build.sh` → `python3 akashi/inspect_all.py --doctor --hotfix` 가 모두 통과.
2. `python3 akashi/privacy_scan.py` → 통과.
3. 사용자 허락 → `python3 akashi/install.py`(사용자 앱에) → 사용자가 써 본다.
4. 사용자 허락 → `python3 akashi/release.py --notes 글.md`.
