# 고침 꾸러미 — 다시 설치하지 않고 고친다 (`c17c84c` · `63eae66` · `c730884`)

사용자: "깃헙 저장소 … 브런치에다가 … 개인정보 빼고 업데이트로 다운받아서 고치게 하면 안되나".

바깥 서비스는 질의 번호 · 응답 이름 · 차단 방식을 수시로 바꾼다. 그때마다 새 판을 굽고 DMG 를 받게 하면 늦다.
그래서 앱이 공개 저장소의 **`hotfix-mac` 가지(고아 가지) · `hotfix/` 폴더**에서 고친 값을 받아 쓴다.
설정 → 유지보수 → 「고침 꾸러미」 에 자동 받기 켜고 끄기와 「지금 확인」 이 있다.

## 파일

| 파일 | 내용 | 앱이 받는 모양 (`Common::applyHotfix`) |
|---|---|---|
| `api_overrides.json` | 질의 번호·해시 | `twitter.*` 는 `^/i/api/graphql/[A-Za-z0-9_-]{10,40}/[A-Za-z]{3,40}$` 경로만 · `twitter.bearer` · `instagram.*DocId` 는 숫자 · `instagram.*Providers` 는 relayprovider 이름 목록 |
| `shape_aliases.json` | 응답 이름 별명 `{"posts": ["records"]}` | 영숫자·밑줄 1~64자만 |
| `repair_rules.json` | 수리 도우미 규칙 | 무늬는 **글자 그대로의 대안**(`가\|나`)만 · 할 일은 `""` `refreshAllTokens` `updateModules` `repairPython` 만 · 글에 링크 금지 |
| `hotfix.json` | `version` · `minApp` · `notes` | `minApp` 보다 옛 앱은 받지 않는다 |
| `tools/<이름>.py` | 파이썬 도우미 | **앱에 이미 있는 이름**만 갈아 끼운다 |
| `manifest.json` · `manifest.sig` | 파일마다 sha256 · 그 서명 | 아래 |

★ 왜 모양을 좁게 받나 — 데이터도 해칠 수 있다. 끝점 주소를 딴 서버로 돌리면 쿠키가 그리로 간다. 정규식 하나가
앱을 멈출 수 있다(재앙적 되추적). 링크 달린 안내 글은 낚시가 된다. 그래서 '고칠 수 있는 모양' 만 받는다.

## 서명

- `manifest.json` 을 ECDSA P-256 / SHA-256 으로 서명해 `manifest.sig`(DER)로 둔다(openssl).
- 앱은 컴파일해 넣은 공개 열쇠(`src/core/HotfixSig.cpp`, X9.63 65바이트)로 확인한다(Security.framework `SecKeyVerifySignature`).
- **서명이 없거나 틀리면 꾸러미를 통째로 버린다.** 파일 하나라도 sha256 이 어긋나면 그 판을 버린다. 저장소 계정을 빼앗겨도
  서명 열쇠가 없으면 앱이 받을 꾸러미를 만들 수 없다.
- 도우미는 켤 때마다 다시 대 본다(`loadHotfixFromDisk`) — 꺼진 사이 누가 고쳤으면 지운다.
- 비밀 열쇠: `~/.config/hanishiki/hotfix_signing_key.pem`(0600, 저장소 밖). **찍지도 커밋하지도 않는다.** 발행기는 열쇠가
  저장소 안에 있으면 멈춘다. 잃으면 새 열쇠를 만들고 공개 열쇠를 바꾼 **새 판을 구워야** 한다(옛 앱은 새 서명을 못 믿는다).

## 앞서는 차례

- 값: 사용자가 설정에서 손으로 넣은 것 > 받은 꾸러미 > 앱에 든 기본값 (`Common::apiOverride`).
- 파이썬 도우미: 서명된 꾸러미 > 자가 수리가 받은 것(`script_overrides`) > 앱에 든 것 (`Common::activeToolScriptPath`).
  `PYTHONPATH` 끝에 앱의 도구 폴더를 둬, 갈아 끼운 도우미가 옆 모듈(`x_session` 등)을 그대로 불러온다(`bundledProcessEnv`).
- 되돌리기: 설정의 「파이썬 도우미 되돌리기」(`resetHotfixTools`).

## 언제 받나

켠 뒤 20초, 그 뒤 12시간마다(자동이 켜져 있을 때). 받은 것은 자료 폴더의 `hotfix/` 에 두어 인터넷이 없어도 쓴다.
시험할 땐 `HANISHIKI_HOTFIX_BASE=http://127.0.0.1:8765/hotfix/` 로 로컬 서버를 가리킨다.

## 내는 법

1. `mac/chernobyl/hotfix/` 를 고친다. `hotfix.json` 의 `version` 을 **올린다**(안 올리면 앱이 새로 받지 않는다).
2. `python3 mac/chernobyl/tools/hotfix_publish.py` — 모양 검사 · 개인 정보 훑기 · manifest · 서명 · `hotfix-mac` 에 커밋(임시 작업 트리).
3. **밀기(push)는 사용자의 허락을 받고** 따로 한다. raw.githubusercontent 가 새 가지를 내주기까지 30초쯤 걸린다.

## 시험 — `hotfix_lab.py`

```bash
python3 akashi/hotfix_lab.py selftest   # 앱 없이 · 진짜 열쇠 없이(버릴 열쇠로) 30가지
python3 akashi/hotfix_lab.py run --replace
```
여덟 가지를 격리 사본에 먹인다: 제대로 된 것(받음) · manifest 바꿔치기 · 도우미 바꿔치기 · 서명 없음 · 낯선 열쇠 ·
새 판 필요(minApp) · 앱에 없는 도우미 이름(그것만 버림) · 판 올림. 끝에 사본을 끄고, 꺼진 사이 도우미를 몰래 고친 뒤
다시 켜서 버리는지까지 본다. 시험 꾸러미는 진짜 열쇠로 서명되므로 끝나면 지운다.
