# 배포(DMG) 동봉 파일

## `카메라_개발자인증.command`
DMG 로 받은 카메라.app 을 사용자가 본인 Mac 에서 코드서명·인증해 실행하는 도구.
- 앱 경로 자동 탐지 + 번호 선택(엔터=자동) / 직접 경로 입력
- 개발자 인증서 자동 탐지 + 번호 선택(엔터=자동) / 직접 ID 입력 / 인증서 없으면 ad-hoc
- 격리(quarantine) 제거 → '손상되어 열 수 없음' 해제
- inside-out 서명(내부 dylib/.so 먼저 → --deep) + 검증

DMG 빌드 시 스테이징 폴더에 `① 개발자 인증.command` 로 복사해 동봉한다.
