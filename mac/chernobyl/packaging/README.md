## `카메라_개발자인증.command` — 지금 DMG 에는 들어가지 않습니다
앱 이름이 카메라이던 시절, DMG 로 받은 앱을 사용자가 본인 Mac 에서 코드서명·인증해
실행하게 하던 도구입니다. 그때는 DMG 빌드가 이 파일을 `① 개발자 인증.command` 로 복사해 넣었습니다.
- 앱 경로 자동 탐지 + 번호 선택(엔터=자동) / 직접 경로 입력
- 개발자 인증서 자동 탐지 + 번호 선택(엔터=자동) / 직접 ID 입력 / 인증서 없으면 ad-hoc
- 격리(quarantine) 제거 → '손상되어 열 수 없음' 해제
- inside-out 서명(내부 dylib/.so 먼저 → --deep) + 검증

지금 그 역할은 `resources/dmg/첫실행_준비.command` 가 합니다 — 서명은 하지 않고 이 앱 하나의
격리 표시만 뗍니다(서명은 빌드 때 `codesign_app.sh` 가 이미 해 둡니다).
