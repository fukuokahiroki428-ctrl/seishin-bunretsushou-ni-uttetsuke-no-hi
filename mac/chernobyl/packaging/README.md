# 배포(DMG) 동봉 파일

`make_dmg.sh` 는 `resources/dmg/` 안의 파일을 통째로 DMG 에 넣고(`.command` 에 실행 권한), 여기 있는
`ハンイシキ_개발자인증.command` 하나를 더 넣습니다. 이 파일이 없으면 DMG 를 만들지 않습니다 — 앱의 안내
(서명 인증서가 만료됐을 때 · `codesign_app.sh` 의 거절 문구)가 이 파일을 가리키기 때문입니다. 원본은 여기 하나만 둡니다.

## `ハンイシキ_개발자인증.command` — 코드 서명 다시 하기
서명 인증서가 만료됐거나 새로 받았을 때 사용자가 직접 돌립니다(예전 이름: `카메라_개발자인증.command`).
- 앱을 번들 식별자(`com.hanishiki.app`)로 찾습니다(~/Applications · /Applications · 이 파일 옆 · 다운로드 · 데스크탑) — 직접 경로도 됩니다.
- 앱이 켜져 있으면 끄게 합니다(켠 채로 서명하면 앱이 죽습니다).
- 이 Mac 의 서명 인증서를 고릅니다 — 이름이 아니라 지문(SHA-1)으로 서명합니다(갱신하면 같은 이름이 둘 생깁니다).
  인증서가 없으면 임시 서명(ad-hoc)을 고를 수 있습니다 — 그때 macOS 의 권한(전체 디스크 접근 · 자동화 등)을 다시 허락해야 합니다.
- 앱에 든 `codesign_app.sh` 로 서명합니다(빌드 · 앱의 자동 복구와 같은 방식). 이 파일로 직접 고른 임시 서명만 허락합니다
  (`ALLOW_ADHOC=1` — 앱이 혼자 임시 서명으로 바꾸는 것은 막혀 있습니다).

첫 실행의 격리 표시 떼기는 `resources/dmg/첫실행_준비.command` 가 합니다(서명은 하지 않습니다).
