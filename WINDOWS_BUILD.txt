Windows 빌드 안내
=================

이 파일은 요약이다. 자세한 내용과 릴리즈 절차는 README.md 를 봐라.

■ 자동 빌드 (권장)
  main 에 push 하거나 v* 태그를 push 하면
  .github/workflows/build.yml 이 GitHub 의 Windows 러너에서 자동 빌드한다.
    - 결과물: Actions 탭 → 해당 실행 → Artifacts
    - v* 태그면 '초안(draft)' 릴리즈에 Predormition_Setup.exe 가 올라간다
      (mac DMG 를 추가한 뒤 발행 — README '릴리즈 배포 절차' 참고)

■ 로컬 빌드 (Windows PC)
  요구: Qt 6.7 이상(MSVC), CMake 3.20+, Visual Studio 2022 빌드 도구
    1) 외부 도구 받기:  bash windows/scripts/download_windows_tools.sh
    2) Python 번들:     windows\scripts\bundle_python_win.bat
    3) 빌드:
         cd windows
         cmake -B build_win -G Ninja -DCMAKE_BUILD_TYPE=Release ^
               -DAPP_NAME=Predormition -DAPP_ID=com.predormition.app
         cmake --build build_win -j
    4) 배포 폴더 구성은 워크플로의 Deploy 단계를 참고
       (windeployqt + resources 복사 + python_env 복사)
    5) 설치본: Inno Setup 6 으로 windows/predormition.iss 컴파일

■ 주의
  - 앱/설치본 이름은 Predormition (구 이름 Chernobyl · カメラ)
  - 스테이징 폴더는 dist/win 으로 짧게 유지한다 —
    python_env 의 깊은 경로가 Windows MAX_PATH(260자)에 걸린다
